## 关键证据及证据分析

对照 `设置页流程与设置项分析.html` §三的 14 项编号，逐项回写修复与代码定位。

### P0（3 项空悬开关）
- **P0-1 动画效果**：移除入口（无消费方，接线不如删除）。删除 `GeneralSettingsSection.kt` 的 `SettingSwitch`、`GeneralSettingsActions.onToggleAnimations`、`SettingsScreen` 形参、`SettingsBranch` 传参、`MainViewModel.updateAnimationsEnabled`。`AppSettings.animationsEnabled` 字段与 `AppPreferences` 读写**保留**（r5 前向兼容：备份 JSON 仍可读写该键，仅不再有 UI 入口）。全仓已无 `onToggleAnimations` / `updateAnimationsEnabled` 引用（测试中的 `animationsEnabled` 仅为备份兼容断言，保留）。
- **P0-2 歌词缓存**：新增进程级快照 `lyrics/LyricsCachePolicy.kt`（单一写入者 = `NasMusicApp` 的 `appSettings` 收集器 + 启动期播种）；`LyricsPersistentCache.get/put` 在锁内读该开关，关闭时不读不写。关闭后 `get()` 返回 null → `LyricsManager.getLyrics` fall through 到网络匹配（`LyricsManager.kt:189`），歌词仍可显示，只是不落缓存，语义与文案"匹配到的歌词自动保存到本地"一致。`clear()/size()` 不受开关影响（清理入口始终可用）。
- **P0-3 封面缓存**：`NasMusicApp.newImageLoader()` 改为委托 `buildImageLoader(coverDiskCacheEnabled)`，开关关闭时不配置 `diskCache`；开关变化时经 `Coil.setImageLoader()` 重建 loader（Coil 2.5.0 标准 API，已核实）。启动期用 `bootSettings.cacheCover` 播种，避免首帧早于异步收集。

### P1（状态/门控不一致 + 电台，共 5 项）
- **P1-1 百度开关语义**：`SourcesSettingsSection` 的开关描述改为三态——未启用 / 已启用未登录（新增 `settings_netdisk_enabled_not_logged_in`）/ 已启用且已登录（`..._enable_active`），`checked` 仍绑 `baiduEnabled`（保持切换语义），消除"开关说谎"。
- **P1-2 下载总开关入口**：新增 `backend/download/DownloadGate.kt` 快照（`NasMusicApp` 单一写入者）；`UnifiedSongRow` 在 `Idle/Failed` 态且总开关关闭时隐藏 ⬇（进行中/已完成仍可见，HDFS 语义不变）；`DownloadViewModel.downloadNow` 关闭时弹一次性 Toast（`settings_download_disabled_toast`），不再静默 return。
- **P1-3 无损档位与设备能力**：`QualityTiers` 新增 `uiTiers()` / `isLosslessUnsupported()`（与既有 `clampForDevice` 并存的 UI 事前过滤）；`PlayerSettingsSection` 与 `QualityPickerDialog` 遍历 `uiTiers()`，不支持 FLAC 的设备不展示无损档；已持久化旧无损值时，卡内显示降级说明（`settings_quality_lossless_unsupported`）。播放侧 `clampForDevice` 兜底保留。
- **P1-4 搜索空态文案**：`MainViewModel.noNetworkSourceEnabled` 改名 `noMusicSourceEnabled`，判据纳入全部 5 个实际参与搜索的源（`nasMusicEnabled` / `localMusicEnabled` / meting / baidu `isActive` / jamendo），链路 `LibraryBranch → LibraryScreen → SearchTab` 同步改名。NAS/本地开着但无结果时不再误报"未启用任何音乐源"。
- **P1-5 电台采集门控**：`SmartRadioManager` 新增 `localMusicEnabled` / `metingEnabled` 两个实时 provider 构造参数（默认 `{ true }`，无破坏性），`loadLibrary` 采集侧直接短路本地库读取与 Meting 歌单请求；缓存键纳入两个新可见性位，关源翻转立即失效重算。`NasMusicApp` 注入 `cachedLocalMusicEnabled` 与 `isSourceEnabledSync(METING_SOURCE)`。既有 NAS provider 语义不变。

### P2（4 项，结构/联动）
- **P2-1 自动下载上限联动**：`DownloadSettingsSection` 以 `downloadEnabled && autoDownloadOnPlay` 为 `limitEnabled`，文案切到 `settings_auto_download_limit_disabled`；`SettingsComponents.AdjustButton` 新增 `enabled` 形参透传 `SettingsTile`（`onClick = { if (enabled) ... }` 内部拦截，与全仓置灰按钮同口径）。数字保留，仅禁用加减。
- **P2-2 默认源当前值可见**：`SourcesSettingsSection` 卡⑥始终渲染 `SettingsInfoRow`（`settings_default_source_current`），自愈切到非 catalog 源（百度/Jamendo）时显示警示（`settings_default_source_not_catalog`）解释"不提供目录、仅作 fallback 起点"。
- **P2-3 缓存清理入口语义**：封面相关三个清理入口上方加分组说明 `SettingsHint`（`settings_cache_cover_group_hint`），点明"图片缓存 / 提取封面文件 / 封面地址索引"三者区别。未做"合并入口 / 显示释放 MB"（属信息架构增强，超出最小修复范围，另立任务）。
- **P2-4 百度索引重建门控**：重建按钮 `enabled = baiduEnabled && baiduLoggedIn`，三态描述（未启用 / 未登录 / 可重建，`..._rebuild_need_enable` / `..._need_login`），关闭时不可发起全盘扫描。
